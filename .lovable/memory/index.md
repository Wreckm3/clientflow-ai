# Project Memory

## Core
ClientFlow AI — SaaS for freelancer client outreach. Mobile-first, Kenyan market focus.
Primary: emerald green (158 64% 40%), Accent: warm amber (25 95% 53%), Inter font.
Lovable Cloud enabled. Edge functions: generate-message, analyze-reply, client-targeting, create-payment, payment-webhook.

DB tables: profiles, message_history, payments. Usage tracked via check_and_increment_usage RPC.
